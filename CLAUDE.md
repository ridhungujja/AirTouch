# AirTouch — notes for Claude

## Project
Building a better webcam hand-tracking "air trackpad" / air-drawing app for the owner's MacBook Air M4 (16 GB) + iPhone 13 Pro (Continuity Camera). Research lives in `reports/` and `research_notes/`.

## Owner preferences
- For web research (Reddit, YouTube, Hacker News, Product Hunt, reviews), prefer **Claude in Chrome** when it's connected — the cloud sandbox's network blocks those sites. If Chrome isn't available, fall back to web search snippets + `gh api search/issues`.
